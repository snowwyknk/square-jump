Square Jump - Ultimate Edition v2.0

Платформер с бесконечной генерацией уровней, системой прокачки, магазином и редактором уровней. Игрок управляет кубом, который должен преодолевать препятствия, собирать аметисты и проходить уровни.

🚀 Установка и запуск
Требования
Python 3.8 или выше

Pygame 2.5.0 или выше

Установка
bash
# Клонирование репозитория
git clone https://github.com/yourusername/square-jump.git
cd square-jump

# Установка зависимостей
pip install pygame numpy
Запуск
bash
python game.py
🎯 Управление
В игре
Пробел / Вверх / ЛКМ — прыжок

H — активация щита

B — ускорение

Q — дэш (ускоренный рывок)

P — пауза

F10 — принудительное завершение уровня (для тестирования)

F9 — отладка системы прокачки

F11 — переключение полноэкранного режима

ESC — назад/выход

В редакторе уровней
1/2/3 — выбор типа объекта

ЛКМ — поставить/выбрать объект

ПКМ — удалить объект

DEL — удалить выбранный объект

A — добавить аметист

C — очистить уровень

G — вкл/выкл привязку к сетке

H — показать/скрыть сетку

Ctrl+S — сохранить уровень

Ctrl+L — загрузить уровень

Shift+Колёсико — прокрутка по вертикали
